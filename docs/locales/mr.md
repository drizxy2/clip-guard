# Clip Guard

Clip Guard हे प्रायोगिक ब्राउझर एक्स्टेंशन आहे. संशयास्पद शेल कमांड क्लिपबोर्डवर लिहिली जाण्यापूर्वी किंवा पृष्ठावर पेस्ट होण्यापूर्वी ते सूचना देते. याच्या अंदाजामुळे चुकीच्या सूचना येऊ शकतात किंवा धोके सुटू शकतात; हे ऑपरेटिंग सिस्टमच्या सुरक्षा उपायांचा पर्याय नाही.

## इंस्टॉल करा

[नवीनतम रिलीझ](https://github.com/drizxy2/clip-guard/releases) डाउनलोड करून अनझिप करा.

- **Chrome, Edge, Brave आणि इतर Chromium ब्राउझर:** `chrome://extensions` किंवा `edge://extensions` उघडा, Developer mode सुरू करा, **Load unpacked** निवडा आणि `manifest.json` असलेले अनझिप केलेले फोल्डर निवडा.
- **Firefox:** AMO वर स्वाक्षरी व प्रकाशन होईपर्यंत, `about:debugging#/runtime/this-firefox` येथे अनझिप केलेली `manifest.json` निवडून तात्पुरते लोड करा. Firefox बंद केल्यावर तात्पुरते एक्स्टेंशन काढले जाते.

## संरक्षण आणि गोपनीयता

Block मोड तुमचा निर्णय होईपर्यंत संशयास्पद लेखन किंवा पेस्ट थांबवतो. Warn-only मोड कृतीला परवानगी देतो आणि सूचना दाखवतो. Clip Guard नेटवर्क विनंत्या करत नाही आणि क्लिपबोर्डवरील मजकूर जतन करत नाही. ऐच्छिक स्थानिक मोजमाप सुरू असल्यास फक्त स्रोत, पातळी, कारणे आणि तारीख नोंदवली जातात. तुमच्या निर्णयाच्या प्रतीक्षेतील मजकूर काही काळ मेमरीत राहतो.
