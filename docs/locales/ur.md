# Clip Guard

Clip Guard ایک تجرباتی براؤزر ایکسٹینشن ہے جو مشتبہ شیل کمانڈز کو کلپ بورڈ میں لکھے جانے یا کسی صفحے پر پیسٹ ہونے سے پہلے خبردار کرتا ہے۔ اس کے اندازے غلط انتباہ دے سکتے ہیں یا خطرات پہچاننے سے چوک سکتے ہیں؛ یہ آپریٹنگ سسٹم کے تحفظ کا متبادل نہیں۔

## انسٹال کریں

[تازہ ترین ریلیز](https://github.com/drizxy2/clip-guard/releases) ڈاؤن لوڈ کر کے نکالیں۔

- **Chrome، Edge، Brave اور دیگر Chromium براؤزر:** `chrome://extensions` یا `edge://extensions` کھولیں، Developer mode فعال کریں، **Load unpacked** منتخب کریں، پھر نکالا ہوا وہ فولڈر چنیں جس میں `manifest.json` ہو۔
- **Firefox:** AMO پر دستخط اور اشاعت تک، `about:debugging#/runtime/this-firefox` میں نکالی گئی `manifest.json` منتخب کر کے عارضی طور پر لوڈ کریں۔ Firefox بند ہونے پر عارضی ایکسٹینشن ہٹا دی جاتی ہے۔

## تحفظ اور رازداری

Block موڈ آپ کے فیصلے تک مشتبہ تحریر یا پیسٹ روکتا ہے۔ Warn-only موڈ کارروائی کی اجازت دے کر انتباہ دکھاتا ہے۔ Clip Guard نیٹ ورک درخواستیں نہیں کرتا اور کلپ بورڈ کا متن محفوظ نہیں کرتا۔ اختیاری مقامی پیمائش فعال ہو تو صرف ماخذ، سطح، وجوہات اور تاریخ درج ہوتی ہے۔ فیصلے کی منتظر عبارت کچھ وقت کے لیے میموری میں رہتی ہے۔

انٹرفیس براؤزر کی زبان استعمال کرتا ہے۔ تکنیکی تفصیل کے لیے [پروجیکٹ README](../../README.md) دیکھیں۔
