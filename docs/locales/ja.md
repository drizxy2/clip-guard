# Clip Guard

Clip Guard は実験的なブラウザー拡張機能です。不審なシェルコマンドがクリップボードに書き込まれたり、ページに貼り付けられたりする前に警告します。ヒューリスティック判定は誤検知や見逃しを起こす場合があり、OS のセキュリティ機能に代わるものではありません。

## インストール

[最新リリース](https://github.com/drizxy2/clip-guard/releases)をダウンロードして展開します。

- **Chrome、Edge、Brave などの Chromium ブラウザー:** `chrome://extensions` または `edge://extensions` を開き、デベロッパーモードを有効にして、**パッケージ化されていない拡張機能を読み込む**を選び、`manifest.json` を含む展開先フォルダーを指定します。
- **Firefox:** AMO で署名・公開されるまでは、`about:debugging#/runtime/this-firefox` で展開した `manifest.json` を選び、一時的に読み込みます。一時的な拡張機能は Firefox を閉じると削除されます。

## 保護とプライバシー

ブロックモードは、不審な書き込みや貼り付けをユーザーが判断するまで停止します。警告のみのモードは操作を許可して警告を表示します。Clip Guard はネットワークリクエストを行わず、クリップボードのテキストを保存しません。任意のローカル測定を有効にした場合、記録するのは発生元、レベル、理由、日付のみです。判断待ちのテキストは一時的にメモリに保持されます。

画面の言語はブラウザーの言語に従います。技術的な詳細は[プロジェクト README](../../README.md)をご覧ください。
